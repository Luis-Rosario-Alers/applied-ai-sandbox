## Plan from chat

Note pinning — implementation design
What we're adding
A pin icon next to each note's title. Clicking it marks that note as pinned, which moves it to the top of the list (behind any other pinned notes). Clicking again unpins it.

Data change
Each note dict currently has title, description, tags, and pinned. No change needed there — pinned already exists. Just make sure any code that creates a new note sets pinned: False by default.

Backend — app.py
Add one new route:
POST /notes/<note_id>/pin
This route finds the note by its ID, flips its pinned value (True → False, False → True), then redirects back to the home page.
Also update the existing index route so it separates pinned and unpinned notes before passing them to the template. Pinned notes go first, unpinned after. The simplest way is two list comprehensions — one filtering where pinned == True, one where pinned == False — then concatenate them and pass the combined list to the template.

Frontend — home.html
Next to each note's title, add a small form with a POST button styled as a pin icon. The form's action points to /notes/<note_id>/pin. No JavaScript needed — a plain HTML form submit works fine.
To visually distinguish pinned notes, add a CSS class (e.g. pinned) to their card when note.pinned is True, and use it to highlight the pin icon.

Ordering logic
The ordering happens in Python, not the template. When the index route builds the notes list to pass to the template, it should be:
[...all pinned notes in their current order...] + [...all unpinned notes...]
A newly pinned note gets appended to the end of the pinned group (i.e. it goes behind any already-pinned notes), which satisfies the acceptance criteria.

Existing tests
Before touching anything, run the test suite and confirm it's green. After your changes, run it again. The new route and the reordering logic are the two things most likely to affect tests — make sure note creation still defaults pinned to False, and that the index route still returns all notes (just in a different order).

Order of work

Confirm every new note dict includes "pinned": False
Add the POST /notes/<note_id>/pin route to app.py
Update the index route to sort pinned notes to the front
Add the pin form button to each note card in home.html
Add a CSS rule to highlight the icon when note.pinned is True
Run tests
