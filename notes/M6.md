# M6 — Other Tools Tour

## Copilot — installed/demo'd
- Observation: Copilot seems to be good for writing "boilerplate" code and autocompleting common coding patterns

## Cursor (or Windsurf) — installed/demo'd
- Observation: Good for explaining files and small multi file changes.

## Gemini CLI (or Codex CLI) — installed/demo'd
- Same prompt comparison: Seems to be slightly less precise than claude code at explaning things but generally still acceptable.

## Chat (Claude.ai or ChatGPT) — used for
- Observation: Something that Claude.ai caught that I would want a junior reviewer to flag would be the `render_template` call on GET not passing `title`, `body`, or `error` kwargs which could potentially raise an `UndefinedError`.

## Tool decision matrix
| Situation | Tool I'd reach for | Why |
| --- | --- | --- |
| Multi-file feature with good CLAUDE.md |Claude Code|A good `CLAUDE.md` allows Claude Code to work within the repository much more efficiently and reduces the number of errors can could be introduced.|
| 5-line helper autocomplete while typing | GitHub Copilot | Has robust capabilities for autocompletion of boilerplate code and common coding patterns.|
| Brainstorm three design approaches |Gemini|Gemini has a good understanding of coding design patterns|
| Review a teammate's PR for security issues | Claude.ai |Claude.ai has better models for code review and explains errors in simple language.|
| Cross-file refactor with consistent renames |Cursor|Composer allows for multi-file diffs based on one properly composed prompt|
| Learning a new library's API |Claude.ai/Gemini| Both can explain in simple language what a library's API is supposed to accomplish and how to code common design patterns using those libraries.|
